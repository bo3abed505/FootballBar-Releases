# API Contract

## Purpose
This document specifies the REST / WebSocket contracts between the FootballTray backend API and client applications (including the WinUI 3 desktop client).

## Topics Covered
- Endpoint specifications and request/response JSON schemas.
- WebSocket / SSE live event streaming protocols.
- Authentication, API versioning, and error code taxonomy.
- Client caching and polling headers (ETag, Cache-Control).
